## 💡 Ringkasan Proyek & Ide Bisnis Tim

* **Domain Masalah:** Kesulitan UMKM mikro dan penjual rumahan dalam menjangkau calon pembeli terdekat akibat pembatasan algoritma organik media sosial, mahalnya biaya promosi berbayar, tingginya potongan komisi marketplace, dan beban biaya ongkos kirim (*shipping fee*).
* **Solusi Terpilih (Setelah Validasi):**  
  **Platform Etalase Hyperlocal UMKM Berbasis Radius (<3–5 KM) dengan Direct Order WhatsApp**
* **Proposisi Nilai Kunci:**
  * **Hyperlocal Discovery:** Pembeli menemukan aneka makanan dan produk tetangga sekitar dalam radius mikro.
  * **0% Commission / Tanpa Potongan Biaya:** Transaksi langsung terhubung ke WhatsApp penjual, menjaga margin keuntungan 100% milik pedagang kecil.
  * **Bebas Beban Ongkir:** Mendukung opsi *Self-Pickup* (ambil sendiri) atau *Antar Langsung* oleh pedagang.
